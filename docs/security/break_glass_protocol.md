# Emergency Break-Glass Protocol

- **Authorized Roles**: District Magistrate (DM) and Superintendent of Police (SP).
- **Condition**: Active threat or abduction under Tier 4.
- **Constraints**: Mandatory 50+ character justification.
- **Access Window**: Strictly 4 hours with automatic session revocation.
- **Auditing**: SHA-256 hash-chained immutable logging.

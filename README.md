# NHAA-Care: AI-based Dynamic Mental Health Monitoring & Distress Prediction System

An enterprise-grade, trauma-informed, privacy-compliant public health and justice-support platform engineered under the **Scheduled Castes and Scheduled Tribes (Prevention of Atrocities) Act, 1989** and the **Digital Personal Data Protection (DPDP) Act, 2023**.

Developed for deployment across 760+ districts in India, integrating with the National Helpline Against Atrocities (14566), state integrated grievance portals, mobile applications, and sovereign IVRS infrastructure.
